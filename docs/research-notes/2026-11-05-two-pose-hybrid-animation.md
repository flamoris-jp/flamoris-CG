# 2枚の原画から、2DとCGを組み合わせる手のアニメーションへ

研究日：2026年11月4〜5日。愛乃と美祥による制作実験の整理。
会話の逐語録ではなく、成果物・実装・確認結果を基にした要約です。

**現時点の到達点は、原画を使う片腕の2D動画と、原画に厚みを付けて回すBlenderの手を、それぞれ作成できたこと。** 両者を同じキャラクターへ合成する工程は次の課題です。任意の2枚から完成アニメーションを自動生成する仕組みは、まだできていません。

## 目的と評価の軸

出発点は、2枚の絵の頭・肩・肘・手などの対応から中間の動きを計算できないか、という発想でした。途中から目標を「線がしっかり描画され、塗りに破綻がないこと」に絞りました。原画らしさ、自然な動き、塗りの被覆は別々に評価します。穴がないという数値だけで、美術的に自然とは判断しません。

入力は同じ制作セッションで生成・提供されたAkinoの2枚の原画（各1122×1402）。対応点、部品のマスク、肩の位置、描画順、隠れた部分の補完は手動で設計しました。元画像や大容量の動画・モデルはリポジトリに同梱せず、コード・手順・小さな確認記録を残します。

## 実験の経過

| 段階 | 試した方法 | 分かったこと・残った問題 |
| --- | --- | --- |
| フェードと全身メッシュ | 対応点から画素を移動し、2枚の塗りを補間 | 動きは出るが、線が二重になり、腕・指・服が裂ける。全身メッシュは101時刻の検査で最大10個の反転・退化三角形があった |
| 部位別の画素変形 | 頭、胴、腕、手、脚を分け、滑らかに変形 | 全身の裂けは減るが、袖や指の伸び、二重線が残る。部品の意味と重なりが必要だった |
| 外周線のモーフィング | 線を取り出して輪郭を移動し、塗りと合成 | 線は明瞭になるが、外周だけでは指や親指の内側の線、回転時の隠れ方を説明できない。塗りと別に動かすと位置もずれる |
| 簡略関節と手の回転 | 肩・肘・手首で腕を動かし、掌と親指に厚みを付けて深度判定 | 輪郭と塗りを同じ形から出せる。親指の付け根、重なり、甲と掌の細部が回転を読む手がかりになった。ここまではBlenderを使わない独自CPU描画 |
| 原画を使う片腕 | 原画の袖を変形し、甲はA、掌はBの絵を使用。肩を固定し、衣服・手首を補完 | 原画らしさが改善。横向きの厚み、丸い手首、脇の隙間を修正した。ただし、手の表裏の切替や補完した布の見え方は残る課題 |
| Blenderの簡略手 | 掌・親指・4本の指・爪・掌の線を立体で作って回転 | 実際の立体による厚みと遮蔽を確認。指が離れすぎ、原画と形が違った。袖ごとの軸回転と回す方向も見直す必要があった |
| 原画に合わせたBlenderの手 | 原画の輪郭に対応した閉じた2.5Dメッシュを作り、甲・掌に元の絵を貼る | 指の寄り方、親指、線と塗りが原画へ近づいた。親指が手前を通る方向へ修正。今回の2方向に合わせた成果であり、人体の手の完全な3D復元ではない |

前半の方法と失敗結果は [2ポーズ実験の詳細](../../experiments/two_pose/README.md)、Blenderの初期モデルは [手の回転実験](../../experiments/blender_hand_turn/README.md)、最終の作り方は [原画への適合手順](../../experiments/blender_hand_turn/SOURCE_FIT.md) に記録しています。

## 親指から分かったこと

愛乃が、最初の原画では親指が手前にあり甲側を見ていて、手を上げた原画では親指が奥にあり掌側を見ている、と指摘しました。外周を単に縮めて裏返すだけでなく、親指の位置と付け根の線、指同士の重なり、掌・甲の見える細部を対応させる必要がある、という制作上の手がかりになりました。

最初のBlenderモデルは逆方向の軸回転でした。最終版はカメラを正面（world +Z）に固定し、手首から指先へ向かうlocal Xに対して負の180度回転を設定しています。親指側のlocal Yが負なので、中間では親指がカメラ側へ来ます。画面内の手の傾きも原画Aの約−14.826度からBの約+24.305度へ合わせました。

この回転は選んだ見せ方です。前腕の回内・回外や、肩から手首までの解剖学的な運動を復元した値ではありません。最終の手の単体モデルでは袖・前腕を外しており、固定した袖に手首だけで180度の捻りを負わせる実装には進めていません。

## それぞれの成果と確認範囲

### 原画を使う2Dの片腕

`refine_original_art_joints.py` は、原画Aの体・顔・髪・反対側の腕を固定したまま、片方の腕を動かします。肩の支点は原画座標 (642,625)。袖の原画を使い、Bの無地の白衣から選んだ布で脇の接続を補います。袖に焼き込まれた丸い肌色部分を除き、先細りの手首へ置き換えました。手の横向きには手動設定の側面を描き足しています。

48フレーム、720×900、24fps。実原画の全フレームで、接続帯の未塗り・最終的な腕の穴・編集範囲外の変更・頭部の変更はいずれも0でした。これは宣言したマスク内の被覆と保護の検査です。微小な隙間の補修を記録しており、原始的な形状が初めから完全だったという意味ではありません。袖の裏や衣服の自然さ、手の表裏切替は目視で評価する項目として残ります。

### 原画に合わせたBlenderの手

`fit_source_hand.py` は10組の輪郭の区間を対応付け、共通の三角形分割と厚みから1つの閉じた表面を作ります。指の付け根に別パーツの継ぎ目を作らず、2つの形状キーで原画間の形の違いも補正します。最大の半厚みは手動設定の0.075単位（原画100画素/単位）。甲・掌のテクスチャは元画像から採り、`.blend` 内へ格納します。

最初の試作ではカメラの切れや掌の線の浮きを確認。原画適合版では、横向きで絵の線が新しい側面へ伸びる問題も見つかりました。最終版は面が横を向く区間で元の絵を補完した肌色へ滑らかに切り替えます。これは描画規則として設計した補完であり、見えない面の原画を推定したものではありません。

| 項目 | 最終版の記録 |
| --- | --- |
| 実行 | LIME / Blender 5.2.3 LTS / Cycles CPU / 8 samples |
| 描画方法 | 既存Flamencoの永続JOB。既存シーンとサービス設定を保持 |
| 元の連番 | 32フレーム、800×600、透過PNG、24fps |
| 表示用ループ | 16fps、静止と逆再生を加えた78フレームのタイムライン |
| 形状 | 2,014頂点、4,024面、非多様体エッジ0 |
| 確認 | 全32枚の読み込み・目視、カメラの切れなし。GIF/MP4も全体をデコード |
| 線 | PNG出力後、アルファから2画素の外周線を追加。生のPNGと線付きPNGを両方保存 |
| コードの確認 | 実装時にPythonテスト111件と既存シーンvalidatorが成功。形状キー101時刻で表面三角形の正の面積を確認 |

`.blend` に出力後の外周線処理は含まれません。再現時にはパッケージ処理も必要です。テスト成功は自然な作画や任意のカメラでの正しさを保証しません。実JOBと入力のハッシュは [受入れ記録](../../experiments/blender_hand_turn/source-fit-acceptance.json) にあります。

## 制作上の役割分担

愛乃の提案を基に、次の分担を今後の作業仮説とします。全体の統合は未実装です。

| 担当 | 任せたい役割 | 今回の状態 |
| --- | --- | --- |
| Cutworkなどの原画準備 | 腕・手・袖・胴の分解、隠れた部分の補完、修正可能な素材の保存 | 今回は手動マスク・座標指定・原画の流用で実施。Cutworkの自動機能を実装したものではない |
| 2D変形 | 腕の上下、肘の曲がり、肩と衣服の接続、原画の線と塗りの保持 | 固定した体に片腕を動かす試作あり |
| CG / Blender | 手の表裏の回転、厚み、前後の遮蔽、見えない側面の補完 | 原画に合わせた手単体の試作あり |
| 合成・編集 | 同じ手首と時間で2DとCGを接続し、必要に応じてKachincoへ素材化 | 新しいBlenderの手を2Dの腕へ合成する工程は未実施 |

今回うまくいったのは、原画の見た目を保つ箇所と、奥行きが必要な箇所に異なる表現を使ったことです。ただし、1組の原画を使って複数の条件を変えた探索的な実験なので、特定の線だけの効果や、他の方式に対する優位性を測定した結果ではありません。

## AIとの制作で残った課題

対応点、部品の境界、描画順、隠れた服、厚み、回転方向、側面の塗りを明示して修正する必要がありました。とくに、塗りに穴がなくても見た目が不自然な例や、立体ができても原画に似ていない例がありました。数値の検査と、原画との比較・人間の見た目の判断を両方使う必要があります。

ここからAI全般の能力限界を断定はしません。今回の方法では、自動分解・一貫した隠れ面の復元・解剖学的な回転推定は未達です。修正可能な部品、対応点、共通の手首、補完箇所の記録をツールで共有する方向を次の検証対象とします。

## 次の実験

1. **手首の共通座標を決める。** 2Dの腕とBlenderの手で、接続点・画面内の向き・大きさ・回転角・時刻を共有する。
2. **片腕の動画に接続する。** 既存の2Dの手を置き換え、袖口の前後関係と重なりを設計する。二重線、透明な隙間、手の大きさの跳びを確認する。
3. **捻りを腕へ分散する。** 手首だけでなく前腕・袖も含めて、原画を崩さず回転を見せる方法を比較する。肩の支点と服の接続を同時に守る。
4. **部品と補完を編集可能にする。** Cutworkとの連携候補として、マスク、親子関係、支点、元画像、補完した箇所を保持する形式を検討する。
5. **別の原画でも試す。** 指の開き、反対向きの回転、他の視点で破綻を記録し、この1組に合わせた調整からどこまで一般化できるか調べる。

これらは次の研究候補であり、この記録で実装・配備した機能ではありません。CGは個別の素材クリップの範囲を維持し、Cinemaの制作全体の統括は再開しません。
